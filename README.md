# SellerStatus Mac

Персональная утилита продавца Wildberries. Иконка в строке меню macOS открывает мини-панель, из неё можно перейти к подробному обзору, складам, товарам и финансовому расчёту.

**Версия 0.1 — демонстрационный прототип. Все числа вымышленные.** Приложение не обращается к WB или SellerStatus, не запрашивает токены и не меняет данные магазина.

## Открыть приложение

Архив приложения: `build/SellerStatus-Mac-demo.zip`. Собранное приложение находится в `build/SellerStatus Mac.app`. Откройте его двойным нажатием. В верхней панели появится иконка с тремя столбиками.

- Нажатие на иконку: мини-панель сверху по центру экрана с мягким появлением из области под строкой меню. Повторное нажатие и Escape плавно скрывают её. Предусмотрено скрытие при потере фокуса.
- «Открыть подробности»: полноценное окно.
- Закрытие подробного окна оставляет приложение в строке меню.
- Правая кнопка по иконке: обзор и выход.
- Автозапуск не включён.

Текущая сборка предназначена для Apple Silicon. Подписана локальной ad-hoc подписью для разработки, не опубликована и не нотарифицирована. Работа на других версиях macOS и Intel пока не проверена.

## Что реализовано

- Мини-панель и отдельное окно подробностей; повторный запуск не создаёт ещё одну копию.
- Обзор заказов, выкупов, возвратов, текущего запаса и товаров в пути.
- «Важное»: правила низкого запаса, устаревания данных, неполной себестоимости и отрицательного результата.
- Склады → товары → размеры и баркоды; поиск и комбинированные фильтры.
- Финансовая расшифровка. При неполной себестоимости полный результат не публикуется.
- Периоды «Сегодня», «Вчера», «7 дней». Период меняет операции, но не умножает текущий остаток.
- Светлая, тёмная и системная темы. По умолчанию — системная; выбор сохраняется между запусками и синхронизируется между окнами.
- Демосценарии: обычный день, убыток, неполные данные, устаревшие остатки, пустой кабинет, ошибка.
- Браузерный деморежим с общими React-компонентами.

Уведомления, новости WB, авторизация, реальные поставки, возвраты непосредственно продавцу и постоянный локальный кеш — следующие этапы, не действующие функции прототипа.

## Стек и границы

- **React + TypeScript + Vite** — интерфейс.
- **Redux Toolkit** — состояние интерфейса: период, фильтры, выбранная запись, демосценарий.
- **RTK Query** — загрузка и кеш снимков по аргументам запроса. `currentData` не позволяет показывать снимок прежнего периода под новым заголовком.
- **Go + Wails 3.0.0** — системная иконка, окна и ограниченный мост навигации.
- **SellerStatus / Python** — будущий серверный источник. Его код и рабочие доступы этой задачей не менялись.

React-вью не обращаются к WB. Бизнес-правила и фильтрация вынесены из компонентов. Переход к серверу проходит через адаптер данных; интеграция с платформой изолирована от браузерного режима.

```text
main.go                         # Оболочка macOS, иконка, окна
frontend/src/app/api.ts          # Адаптер снимка / RTK Query
frontend/src/app/store.ts        # Типизированное UI-состояние
frontend/src/app/desktop.ts      # Мост Wails / браузерный режим
frontend/src/data/               # Контракт, демоданные, правила
frontend/src/features/           # Обзор, мини-панель, склад, финансы
frontend/src/components/         # Общие UI-компоненты
frontend/src/styles/             # Общие токены темы и стили контролов
```

## Оформление и анимация

Откройте шестерёнку → «Оформление»: «Светлое», «Тёмное», «Как в системе». Тема сохраняется в `~/Library/Application Support/SellerStatusMac/preferences.json`; в браузерном деморежиме — в localStorage (только эта несекретная настройка).

Панель появляется сверху по центру дисплея под указателем, примерно за 200 мс. Её фон доходит до физического верхнего края экрана и перекрывает центральный участок строки меню, пока панель открыта. Чёрная верхняя полоса визуально соединяется с вырезом. `safeAreaInsets` и высота строки меню удерживают интерактивное содержимое ниже камеры; на дисплее без выреза резервируется высота строки меню. Настоящее окно без заголовка и уровень `NSStatusWindowLevel` позволяют занять эту область. Это собственная панель приложения; системный вырез не изменяется. Используются публичные AppKit API. При включённом «Уменьшении движения» macOS анимация отключается.

При открытии/закрытии меняются положение и прозрачность окна, но не размеры веб-интерфейса: это устраняет временное переполнение и появление скролла из-за анимации. Корневой документ панели не прокручивается; единственная прокручиваемая область — её содержимое, если оно действительно не помещается на небольшом экране.

Период, тема, демосценарий и фильтр запаса используют общий `Select`: стрелки, Home/End, поиск по началу названия, Enter для выбора, Escape для отмены и Tab для перехода дальше. Список раскрывается вверх, если снизу не хватает места, и остаётся внутри фокусной области модального диалога. Escape закрывает сначала список, затем настройки, затем панель.

Тема и размеры текста находятся в `styles/tokens.css`: вспомогательный текст от 11 px, обычный 13 px, заголовки 16–24 px, главные числа 28–36 px. Фиолетовый используется для действий, нейтральные цвета — для содержимого, дополнительные цвета — для значимых состояний. Фокус клавиатуры использует контрастный контур темы. Кнопка обновления общая для обоих окон: блокирует повторное нажатие и вращает значок, пока запрос выполняется. Декоративного бесконечного движения нет.

Основа поведения: [Apple NSScreen safe area](https://developer.apple.com/documentation/appkit/nsscreen/auxiliarytopleftarea-uglc?language=_1), [WAI-ARIA Combobox Pattern](https://www.w3.org/WAI/ARIA/apg/patterns/combobox/). Проверка всей доступности с VoiceOver ещё предстоит.

## Разработка

Нужны Node.js с npm, Go 1.27+ и Xcode Command Line Tools. Версии зависимостей закреплены lock-файлами. При переносе проекта установите Go самостоятельно; подготовленная в этом чате копия инструментария находится вне проекта в рабочей папке.

```sh
cd frontend
npm ci
npm run dev
```

Браузерное демо: `http://127.0.0.1:5188/`; мини-панель: `http://127.0.0.1:5188/?view=panel`. Это локальные адреса, не опубликованный сайт. Данные реального магазина в демоверсию не включаются.

Из корня проекта:

```sh
./scripts/build-macos.sh
./scripts/run-macos.sh
```

Скрипт сборки использует установленный `go`, переменную `GO_BIN` или подготовленный в этом чате инструментарий. Сборка не устанавливает приложение в `/Applications` и не включает автозапуск.

## Проверки

```sh
cd frontend
npm test
npm run lint
npm run format:check
npm run build
```

Из корня проекта, с Go в PATH:

```sh
go test .
```

Проверки охватывают отсутствие двойного учёта остатков, совместную фильтрацию, сохранение контекста после карточки товара, смену периода, неполную себестоимость, отрицательный результат, устаревшие источники и восстановление после ошибки. Отдельная проверка Go запрещает произвольные адреса в мосте навигации.
