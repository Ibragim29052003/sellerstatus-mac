- 6 Go-тестов: прошли, включая `go test -race .`. Проверены границы навигации, сохранение темы, повреждённые настройки, ошибка записи и конкурентное сохранение.

- Prettier check: прошёл.
- npm audit рабочих зависимостей через registry.npmjs.org: 0 известных уязвимостей на момент проверки. Это не полный аудит безопасности приложения.

- Локальная подпись codesign проверена, в том числе после распаковки архива в рабочую папку.

## В самом Mac-приложении

- Приложение запущено, React загрузился внутри Wails.
- Мини-панель открывается, кнопка подробностей вызывает Go-binding и открывает отдельное окно с переданным контекстом.
- Переход к остаткам работает.
- Выбор «Минск» + поиск `Essential` даёт одну позицию и складской остаток 12 шт.
- По умолчанию выбрано «Как в системе»; интерфейс соответствует текущей тёмной теме macOS. Светлая и тёмная мини-панели визуально просмотрены.
- Светлая тема сохранена, приложение закрыто через Cmd+Q и запущено заново: выбор восстановился. После проверки возвращено «Как в системе».
- Настройка темы синхронизируется между подробным окном и мини-панелью.
- Центральная мини-панель открывается после перехода из подробностей. Анимация реализована через AppKit: прозрачность, небольшое изменение размера и положения, 0,2 секунды.
- Escape сначала закрывает открытые настройки; следующий Escape скрывает мини-панель. Повторный запуск открывает панель существующего процесса.
- Предыдущая сборка закрыта через Cmd+Q, обновлённая запущена.

## Ограничения проверки

Встроенный браузер не разрешил открыть локальный предпросмотр из-за настройки Work. Поэтому браузерная проверка на нескольких viewport не выполнена; адаптивные стили есть, но не объявляются полностью проверенными. Основной интерфейс проверен в нативном Wails/WebKit.

Отдельно ещё предстоит проверить поведение на другом мониторе, физическом Intel Mac, старых версиях macOS, длительную фоновую работу и интеграцию с реальным API. Обработка уменьшения движения и скрытия при потере фокуса реализована через публичные AppKit API; автоматизация UI не позволила надёжно подтвердить фактическое переключение фокуса в другое приложение. Эти сценарии и качество анимации при частых кликах требуют дополнительной ручной проверки.

В папке Documents система может добавлять Finder-атрибуты к приложению после запуска; архив подготовлен без этих атрибутов и проверен после распаковки. Собранное приложение не нотарифицировано для публичного распространения.
