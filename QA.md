- 6 Go-тестов: прошли, включая `go test -race .`. Проверены границы навигации, сохранение темы, повреждённые настройки, ошибка записи и конкурентное сохранение.

## Граница реальной интеграции

Прочитан локальный код SellerStatus (`151a8433`). Анонимный `/api/v1/auth/session` ответил 401; `/openapi.json` вернул HTML, а не публичную схему. Эти проверки не являются тестом приватных финансовых или складских ответов. Нужны отдельная авторизация настольного клиента и согласованный агрегированный контракт. Даты, единицы, складская детализация и ограничения текущих маршрутов записаны в `INTEGRATION.md`.

## Ограничения проверки

Встроенный браузер не разрешил открыть локальный предпросмотр из-за настройки Work. Поэтому браузерная проверка на нескольких viewport не выполнена; адаптивные стили есть, но не объявляются полностью проверенными. Основной интерфейс проверен в нативном Wails/WebKit.

Отдельно ещё предстоит проверить поведение на другом мониторе и дисплее без выреза, физическом Intel Mac, старых версиях macOS, длительную фоновую работу и интеграцию с реальным API. Обработка уменьшения движения и скрытия при потере фокуса реализована через публичные AppKit API; автоматизация UI не позволила надёжно подтвердить фактическое переключение фокуса в другое приложение. Эти сценарии, VoiceOver и качество анимации при частых кликах требуют дополнительной ручной проверки. План следующей сессии — в `PROGRESS.md`.

В папке Documents система может добавлять Finder-атрибуты к приложению после запуска; архив подготовлен без этих атрибутов и проверен после распаковки. Собранное приложение не нотарифицировано для публичного распространения.

## Интеграция планировщика — 30 октября

Проверена личная сборка Apple Silicon с self-contained .NET 10. Оригинальный учебный проект не перемещался и не редактировался: подготовка и тесты выполнялись в отдельной копии. Автоматическое подключение WB / SellerStatus не добавлялось.

- 44 исходных C#-теста прошли в копии проекта перед публикацией модуля.
- 55 frontend-тестов прошли. Новые проверки: прямой запуск из панели, блокировка повторных кликов, повтор после ошибки и доступность раздела при ошибке загрузки сводки.
- `go test -race -count=1 .` с настоящим runtime прошёл. Проверены один процесс при конкурентных открытиях, восстановление после остановки ребёнка, постоянный владелец сценариев, недоверенный адрес готовности, неверный health endpoint, тайм-аут, отсутствие runtime, повреждённый идентификатор, ограничение лога и отмена зависшего старта при выходе.
- HTTP-проверка `scripts/test-planner.py` прошла на временных данных, в том числе для runtime из итогового распакованного архива: запрет анонимного доступа и чужого Origin, CSRF, расчёт, JSON/CSV/Excel, импорт, сохранённые копии, повторный запуск на другом порту, изоляция владельцев и остановка по EOF родительского канала.
- TypeScript/Vite, ESLint, Prettier и `git diff --check` прошли.
- Полный пакет подписан локально; проверка `codesign --verify --deep --strict` прошла после распаковки архива в `/private/tmp`. Минимальная версия полной сборки — macOS 14; runtime — `osx-arm64`, self-contained. В синхронизируемой Documents Finder может заново добавлять метаданные, поэтому проверялся также чистый архив.

В самом Mac-приложении пройдено:

1. Боковое меню → запуск планировщика; восстановлен ранее рассчитанный план 821 шт. с 11 позициями.
2. Расчёт через кнопку C#-интерфейса; показаны сводки по складам и раннему дефициту.
3. Сохранение Excel и JSON через NSSavePanel в Downloads. Файлы действительно созданы: 29 432 байта и 74 761 байт; структура XLSX и JSON с 11 позициями проверена.
4. Выбор того же JSON через NSOpenPanel → импорт → подтверждение пересчёта и сохранения предыдущего сценария.
5. Фильтр «Казань» → 2 позиции из 11; раскрытие прогноза футболки, включая дневной график.
6. «Сводка» → мини-панель → «Планировщик»: тот же процесс и сценарий, без запуска дополнительного сервера.
7. Закрытие отдельного окна и повторное открытие; обновление с предупреждением о ещё не применённых изменениях.
8. Светлая тема применена к C#-окну и системной шапке; затем восстановлен исходный выбор «Тёмное».
9. Выход через Cmd+Q: процессы Mac-утилиты и её C#-модуля завершились. После чистого запуска восстановлен сохранённый расчёт.

Во время проверки исправлены задержка старта нативного FileSystemWatcher в синхронизируемой Documents (перезагрузка конфигурации выключена) и обновление `.app` с read-only DLL (пакет заменяется целиком). Проверка управлением UI была выполнена через нативное окно; точная длительность анимаций и полная доступность VoiceOver не измерялись.
