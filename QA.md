## В самом Mac-приложении

- Приложение запущено, React загрузился внутри Wails.
- Мини-панель открывается, кнопка подробностей вызывает Go-binding и открывает отдельное окно с переданным контекстом.
- Переход к остаткам работает.
- Выбор «Минск» + поиск `Essential` даёт одну позицию и складской остаток 12 шт.
- По умолчанию выбрано «Как в системе»; интерфейс соответствует текущей тёмной теме macOS. Светлая и тёмная мини-панели визуально просмотрены.
- Светлая тема сохранена, приложение закрыто через Cmd+Q и запущено заново: выбор восстановился. После проверки возвращено «Как в системе».
- Настройка темы синхронизируется между подробным окном и мини-панелью.
- Мини-панель открывается после перехода из подробностей. Позиционирование изменено на верхний центр доступного экрана с учётом safe area. Анимация реализована через AppKit: прозрачность, небольшое изменение размера и смещение из области верхнего края, 0,2 секунды.
- Проверена компоновка панели 420 × 740: обычная сводка вместе с кнопкой подробностей помещается без вертикальной прокрутки на текущем Mac. На меньшей доступной высоте предусмотрена прокрутка, но отдельный небольшой физический экран не проверен.
- Кастомный селект периода в WebKit работает с End/Enter: выбранные «7 дней» дают 756 выкупов и прежний складской остаток 1040. После проверки возвращено «Сегодня».
- Селект демосценария у нижней границы окна визуально раскрывается вверх.
- Список тем внутри настроек визуально проверен; контур фокуса виден. Escape закрывает список, оставляя настройки открытыми; следующий Escape закрывает настройки. Системная тема сохранена.
- Escape сначала закрывает открытые настройки; следующий Escape скрывает мини-панель. Повторный запуск открывает панель существующего процесса.
- Предыдущая сборка закрыта через Cmd+Q, обновлённая запущена.

## Ограничения проверки

Встроенный браузер не разрешил открыть локальный предпросмотр из-за настройки Work. Поэтому браузерная проверка на нескольких viewport не выполнена; адаптивные стили есть, но не объявляются полностью проверенными. Основной интерфейс проверен в нативном Wails/WebKit.

Отдельно ещё предстоит проверить поведение на другом мониторе и дисплее без выреза, физическом Intel Mac, старых версиях macOS, длительную фоновую работу и интеграцию с реальным API. Обработка уменьшения движения и скрытия при потере фокуса реализована через публичные AppKit API; автоматизация UI не позволила надёжно подтвердить фактическое переключение фокуса в другое приложение. Эти сценарии, VoiceOver и качество анимации при частых кликах требуют дополнительной ручной проверки. План следующей сессии — в `PROGRESS.md`.

В папке Documents система может добавлять Finder-атрибуты к приложению после запуска; архив подготовлен без этих атрибутов и проверен после распаковки. Собранное приложение не нотарифицировано для публичного распространения.
